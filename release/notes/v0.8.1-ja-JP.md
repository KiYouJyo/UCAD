# UCAD v0.8.1 — CAD アイコンシステムと UI 一貫性

- 表示崩れや非表示の原因となっていたオープンパスの `PathIcon` を、集中管理された閉じた塗りつぶしベクター Geometry リソースへ置き換えました。
- Draw、Modify、Annotate、Layer、Block、および拡張オーサリングコマンドのアイコンを ToolShelf、ToolRail、動的コマンドボタンで統一しました。
- Ellipse、Polygon、Spline、Point、Stretch、Fillet、Chamfer、Array、Break、Join などの拡張図形・編集コマンドに専用 CAD アイコンを追加しました。
- CAD 専用ツールでは意味が不安定な Segoe Fluent のグリフコードポイントへの依存を廃止し、設定・その他・表示などのシステム操作には Fluent アイコンを維持します。
- CAD アイコンリソースと旧異常アイコンを検出する回帰契約を追加し、v0.8 のドキュメント、DXF、印刷/PDF、GIS 機能をそのまま維持します。
