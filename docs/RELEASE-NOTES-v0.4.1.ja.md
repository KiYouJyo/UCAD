# UCAD v0.4.1 — CAD Selection & Cursor Interaction Refinement

v0.4.1 は v0.4.0 で構築した選択・作図インタラクションを洗練するリリースです。新しい Modify コマンドは追加せず、一般的な CAD に近いマウス選択操作と、調整可能なクロスヘア、ピックボックス、オブジェクトスナップのアパーチャを導入します。

## 主な変更

- **2 クリックの窓選択**：空白部分をクリックして第1コーナーを指定し、マウスボタンを離したまま移動して選択枠をプレビューし、2 回目のクリックで対角点を指定して選択を確定します。
- **ドラッグ選択も維持**：従来の押下 → ドラッグ → リリースによる選択もショートカットとして引き続き利用できます。
- **Window / Crossing の方向規則**：第1点から右側で確定すると Window（完全に含まれるオブジェクトのみ）、左側で確定すると Crossing（含まれる、または交差するオブジェクト）になります。
- **PICKADD 風の追加選択**：後続のクリックや窓選択は現在の選択セットへ追加され、既存の選択を置き換えません。
- **Shift で選択解除**：Shift を押しながらオブジェクトをクリック、または選択枠を確定すると、該当オブジェクトを現在の選択セットから除外します。
- **Esc の段階的動作**：未確定の 2 点選択がある場合、最初の Esc はその選択枠だけをキャンセルします。選択枠がない状態では Esc で確定済みの選択セットを解除します。
- **CAD カーソル**：作図領域では通常の矢印ではなく、システムの十字ホットスポットと Win2D で描画する CAD クロスヘア＋中央ピックボックスを使用します。
- **クロスヘアサイズ調整**：作図領域に対して 5–100% の範囲で調整でき、既定値は 100% です。
- **ピックボックスサイズ調整**：中央の選択ターゲットを 3–20 px で調整でき、既定値は 6 px です。表示サイズとポイント選択の許容範囲は同じ基準を使用します。
- **OSNAP アパーチャ調整**：オブジェクトスナップの検索範囲を 3–50 px で調整でき、既定値は 10 px です。現在のズームに応じてワールド座標へ変換されます。
- **設定は即時反映**：「設定 → 入力と操作 → CAD カーソル」に 3 項目を追加し、既存の Drawing セッションへ再起動なしで反映します。
- **3 言語対応を維持**：新しい設定説明は簡体字中国語 / 日本語 / English に対応し、v0.3.10 の再起動不要の言語切り替えを維持します。

## 操作

- オブジェクトをクリック：現在の選択セットへ追加。
- Shift + クリック：現在の選択セットから除外。
- 空白をクリック → 移動 → 再クリック：2 点窓選択。
- 左ボタンを押してドラッグ → リリース：クイック窓選択。
- 右方向で確定：Window、左方向で確定：Crossing。
- Shift を押しながら窓を確定：範囲内の対象を選択解除。
- Esc：まず未確定の窓選択をキャンセルし、その後の Esc で確定済み選択を解除できます。

## スコープ

v0.4.1 は操作感の改善版です。MOVE / COPY / ROTATE / SCALE / MIRROR / OFFSET / TRIM / EXTEND は v0.5.x で実装します。今回の選択モデルと CAD カーソル設定を、それらの Modify コマンドの操作基盤として利用します。

## 受け入れ確認

選択ジェスチャーとカーソルサイズは実際のマウス操作感への依存が大きいため、自動テストでは選択セット、Shift 解除、ビルド、起動、パッケージ、バージョン、ローカライズ契約を保証します。リリース前には PR acceptance build で 2 クリック選択、ドラッグ選択、Window/Crossing の方向、Shift 解除、Esc キャンセル、および 3 種類のカーソル設定を手動確認します。
