# UCAD v0.9.3

本版本集中完成 AutoCAD 兼容基础、命令输入体验、三语界面收束，以及 GitHub 应用内更新链路。

## AutoCAD 互操作

- 建立 DWG / DWT / DWS / DXF / DXB 等格式边界，并补齐高频 2D 图元、文字、标注、图块、填充、布局与视口等语义。
- 固定多版本真实 DWG / DXF 回归样本，覆盖 AutoCAD R14 至 2018+ 的主要 DWG 代际，以及 R12 / 2000 / 2018+ DXF。
- 增加 12,000 图元复杂图纸回归，验证大图纸 DWG 往返中的核心图元、图层、图块、标注样式与布局状态。
- 对无法证明可编辑保真的 ObjectARX / Proxy / 自定义对象采用保守的原始容器保留策略：未修改图纸可原字节输出；修改后仍可恢复原始 AutoCAD 源文件。

## 命令输入与动态提示

- 打开或切换到图纸后，底部命令输入框自动获得键盘焦点，可直接输入 CAD 命令。
- 增加 AutoCAD 风格的光标旁动态命令显示框，跟随中心拾取框并自动避让视口边缘。
- 动态框仅承担显示，底部命令行仍是唯一文本输入与 IME 所有者，避免中文/日文输入法冲突。
- 保留 CAD 习惯的 Delete 行为：空命令行时删除已选图元；已有文本时作为正常文本删除键。

## 中文 / 日文 / 英文

- 彻查并补齐 Start 首页、Shell、设置、动态生成工具栏与命令工具的 zh-CN / ja-JP / en-US 支持。
- 修复未展开工具栏一直保留英文的问题，并支持同一运行进程内实时切换语言。
- 增加资源键严格一致性测试和运行时本地化 smoke，避免后续新增功能遗漏某一语言。

## 应用内更新

- “设置 → 常规 → 检查更新”现已接入 GitHub Releases，不再是占位入口。
- 可启用启动后自动检查更新；检查过程不阻塞主界面。
- 仅接受稳定、非草稿、符合 `vX.Y.Z` 的 GitHub Release。
- UCAD 会选择 x64 `.msixbundle`，下载到本地更新缓存，并同时验证 GitHub 资产长度与 `SHA256SUMS.txt` 中的 SHA-256。
- 校验通过后由 Windows 应用安装程序接管安装；UCAD 不进行静默替换，安装仍由用户确认。
- 更新检查、下载进度、错误提示均支持中文、日文和英文。

## 已知边界

- 对修改过的 DWG，目前仍不能把未知 ObjectARX / Proxy / 自定义对象重新注入重建后的 DWG；原始源文件恢复能力保留。
- 更完整的半径/直径/坐标标注、MLEADER、动态块、复杂 HATCH 边界、DXF 布局对象等仍会在后续版本继续扩展。
- DWF/DWFx、CTB/STB/PC3/PMP、DST/DSD 等更外围的 AutoCAD 生态格式仍处于后续规划中。
