# UCAD v0.4.1 — CAD Selection & Cursor Interaction Refinement

v0.4.1 继续完善 v0.4.0 建立的选择与绘图交互，不扩展新的 Modify 命令。本版本重点把鼠标选择手感调整为更接近传统 CAD 的操作逻辑，并引入可调的 CAD 十字光标、拾取框和对象捕捉孔径。

## 主要更新

- **双击点式框选**：在空白处单击确定第一角后即可松开鼠标，移动光标预览选框，再次单击确定第二角并完成选择。
- **保留拖拽框选**：原有按住左键拖动后松开的快捷框选仍然可用，两种手势共存。
- **Window / Crossing 方向逻辑保持一致**：第一角向右完成为 Window（完全包含），向左完成为 Crossing（相交即选）。
- **PICKADD 风格累加选择**：继续点击对象或继续框选会加入当前选择集，不会覆盖已经选中的对象。
- **Shift 减选**：按住 Shift 单击对象或完成选框时，从当前选择集中移除对应对象。
- **Esc 分层取消**：存在未完成的两点框选时，第一次 Esc 只取消当前选框；没有活动选框时，Esc 清除已经完成的选择集。
- **CAD 光标**：进入绘图区后不再使用普通箭头，使用系统十字热点配合 Win2D 绘制的 CAD 十字准线与中央方形 Pickbox。
- **可调 Crosshair**：十字准线长度支持按绘图区的 5–100% 调整，默认 100%。
- **可调 Pickbox**：中央拾取框支持 3–20 px 调整，默认 6 px；对象点选命中范围与可视 Pickbox 使用同一尺寸基准。
- **可调 OSNAP aperture**：对象捕捉搜索范围支持 3–50 px 调整，默认 10 px，并继续按当前缩放转换为世界坐标。
- **即时设置生效**：上述三项位于“设置 → 输入与交互 → CAD 光标”，修改后立即应用到现有 Drawing 会话，无需重启。
- **三语保持**：新增设置说明支持简体中文 / 日本語 / English，并继续跟随 v0.3.10 的无重启语言切换机制。

## 操作

- 单击对象：加入当前选择集。
- Shift + 单击对象：从当前选择集中移除。
- 单击空白处 → 移动 → 再次单击：两点框选。
- 按住左键拖动 → 松开：快捷框选。
- 第一角向右：Window；第一角向左：Crossing。
- Shift + 完成框选：批量减选。
- Esc：优先取消未完成的框选；再次 Esc 可清除已完成选择。

## 范围说明

v0.4.1 是 v0.4.0 的交互精炼版本，不加入 MOVE / COPY / ROTATE / SCALE / MIRROR / OFFSET / TRIM / EXTEND。新的选择模型与 CAD 光标尺寸设置将作为 v0.5.x 修改命令的人机交互基础。

## 验收重点

由于框选与光标尺寸属于高度依赖实际鼠标手感的功能，自动化测试负责保证选择集合、Shift 减选、构建、启动、打包、版本与资源契约；最终发布前还应在 PR acceptance build 中人工验证两点框选、拖拽框选、Window/Crossing 方向、Shift 减选、Esc 取消以及三种光标尺寸设置的实际手感。
