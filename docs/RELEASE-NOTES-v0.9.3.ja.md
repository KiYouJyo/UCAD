# UCAD v0.9.3

このリリースでは、AutoCAD 互換基盤、コマンド入力体験、3 言語 UI の仕上げ、GitHub ベースのアプリ内更新経路をまとめて整備しました。

## AutoCAD 相互運用

- DWG / DWT / DWS / DXF / DXB の形式境界を整備し、主要な 2D エンティティ、文字、寸法、ブロック、ハッチ、レイアウト、ビューポートの意味情報を拡充しました。
- AutoCAD R14 から 2018+ までの主要 DWG 世代と、R12 / 2000 / 2018+ DXF を含む固定実ファイル回帰コーパスを追加しました。
- 12,000 エンティティの複雑図面回帰を追加し、大規模 DWG 往復で主要エンティティ、レイヤー、ブロック、寸法スタイル、レイアウト状態を検証します。
- 編集可能性を保証できない ObjectARX / Proxy / カスタムオブジェクトについては、元の AutoCAD コンテナを保守的に保持します。未編集なら元バイトをそのまま出力でき、編集後も元ソースを回収できます。

## コマンド入力と動的表示

- 図面を開く、または切り替えると、下部のコマンド入力欄が自動的にキーボードフォーカスを取得し、すぐに CAD コマンドを入力できます。
- 中央ピックボックスの横に AutoCAD 風の動的コマンド表示を追加し、カーソルに追従しながら画面端を自動回避します。
- 動的表示は表示専用で、下部コマンドラインだけがテキスト入力と IME を所有するため、中国語・日本語 IME と競合しません。
- 空のコマンドラインでは Delete が選択図形を削除し、文字入力中は通常の文字削除として動作します。

## 中国語 / 日本語 / 英語

- Start ホーム、Shell、設定、コード生成されたツールバーとコマンドツールを zh-CN / ja-JP / en-US で全面点検しました。
- 一度も展開していないツール棚が英語のまま残る問題を修正し、同一プロセス内での即時言語切り替えを検証しました。
- リソースキーの厳密なパリティテストと実動作のローカライズ smoke を追加し、今後の言語漏れを検出します。

## アプリ内更新

- 「設定 → 一般 → 更新を確認」が GitHub Releases に接続され、プレースホルダーではなくなりました。
- 起動後の自動更新確認を任意で有効化でき、確認は UI をブロックしません。
- `vX.Y.Z` 形式の安定版・非 Draft Release のみを受け入れます。
- x64 `.msixbundle` をローカル更新キャッシュへダウンロードし、GitHub のアセット長と `SHA256SUMS.txt` の SHA-256 の両方を検証します。
- 検証後は Windows App Installer に引き渡します。UCAD が無断でインストール済みファイルを置換することはなく、インストールはユーザー確認のままです。
- 更新確認、ダウンロード進捗、エラー表示も 3 言語対応です。

## 既知の境界

- 編集済み DWG に未知の ObjectARX / Proxy / カスタムペイロードを再注入する機能はまだありません。元 AutoCAD ソースの回収経路は保持されます。
- 半径・直径・座標寸法、より完全な MLEADER、ダイナミックブロック、複雑 HATCH 境界、DXF レイアウトオブジェクトは今後の拡張対象です。
- DWF/DWFx、CTB/STB/PC3/PMP、DST/DSD など周辺 AutoCAD エコシステム形式も今後の対象です。
