# UCAD v0.9.4 — PR #19 acceptance gate

This acceptance build exists specifically for the final PR #19 UI/input hardening pass. It is not a public GitHub Release unless explicitly published later.

## Required behavior

- Browser-style document tabs use the Figma-proportioned 60 DIP title strip, 280 × 48 DIP tab cards, 12 DIP rounding, and roomy header/close spacing.
- Button chrome is owned by native WinUI Button/ToggleButton visual states rather than local accent/background overrides.
- All non-canvas shell surfaces use the deep-teal dark palette and light-teal light palette; the CAD drawing canvas palette is isolated and unchanged.
- Physical Delete is reserved for CAD ERASE while `CommandInput` owns focus, even when command text is non-empty or selected. It does not delete command text.
- Delete remains ordinary text editing in unrelated text editors such as command search/settings/dialog inputs.
- When UCAD returns to the foreground with a drawing active, `Window.Activated` schedules command-line keyboard focus recovery.
- Start/Settings pages do not steal drawing command focus because foreground focus recovery is gated by `ActiveSession` and `PageOverlay`.
- Dark/Light theme switching reapplies the matching shell palette without altering `UcadCanvasBrush`.

## Automated gate

Before a signed PR #19 acceptance artifact may be handed off:

1. Core tests pass with zero failures/skips.
2. Release app build passes.
3. Startup smoke launches the real WinUI application and records the PR19 visual/theme marker.
4. Interaction smoke passes.
5. Modify smoke records both the baseline modify marker and the PR19 typed-command Delete/focus marker.
6. Authoring smoke passes.
7. Localization smoke passes for zh-CN / ja-JP / en-US.
8. AutoCAD interoperability passes.
9. x64 MSIX bundle validation, release-certificate signing, one-click validation, and self-contained PR acceptance packaging all pass on the exact PR #19 head.

PR #19 remains Draft/unmerged. After validation its base must be restored to `codex/v0.8-document-dxf-foundation`.
