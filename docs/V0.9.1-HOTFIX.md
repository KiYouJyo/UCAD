# UCAD v0.9.1 AutoCAD Import Compatibility Hotfix

This acceptance hotfix addresses two issues found during manual v0.9.0 testing.

## DWG custom/non-graphical metadata

ACadSharp can successfully open a DWG while emitting many notifications for source-only non-graphical dictionaries and custom objects, for example `WIPEOUTVARIABLES`, `TCH_DBCONFIG`, `ACDBDETAILVIEWSTYLE`, and `ACDBSECTIONVIEWSTYLE`. UCAD v0.9.1 classifies only these known non-graphical metadata notifications as opaque-source diagnostics. They no longer become a blocking import-warning dialog after a successful open.

Unknown graphical entities, failed block references, unsupported visible entities, semantic-repair losses, and layout fidelity losses remain actionable warnings and are not filtered.

The exact original DWG-compatible source container continues to be retained by the opaque source envelope, so filtering a non-graphical metadata notification does not discard the original custom data.

## Discoverable erase command

The existing `ERASE` / `E` / `DELETE` command and keyboard Delete path are now exposed as a visible **ERASE (E)** control in the Modify tool shelf. Modify runtime smoke explicitly requires this control to be visible, enabled, and interactive; command semantics remain covered by Interaction smoke including one-step Undo.

## Version

- Product: `0.9.1`
- MSIX: `0.9.1.0`
- Package identity and publisher remain unchanged for in-place upgrade from v0.9.0.

This file intentionally contains no customer/user DWG data. Regression tests use synthetic diagnostic strings plus the existing pinned public AutoCAD fixture corpus.
