# UCAD v0.2.0 — Command Foundation

v0.2 では、UCAD を単なる描画技術プレビューから、CAD らしいコマンド操作の基盤を持つアプリへ進めました。

## 追加内容

- 画面下部にコマンドラインを追加。
- コマンド登録・エイリアス機構を追加。`LINE` は `L` でも起動可能。
- Enter / Space で入力を確定。
- Esc で実行中コマンドをキャンセル。
- 空入力の Enter / Space で直前のコマンドを繰り返し。
- 絶対座標 `x,y` をサポート。
- 相対座標 `@x,y` をサポート。
- 基点指定後は数値だけを入力して、現在のカーソル方向へ距離指定可能。
- マウス入力と座標入力を同じ LINE 点入力経路へ統合。
- `CLEAR` と `RESETVIEW` も共通コマンドレジストリから実行。
- エイリアス、セッション状態、座標解析の Core テストを追加。

## 入力例

```text
Command: L
0,0
@5000,0
@0,3600
[Enter]
```

`LINE` 開始後にマウスで連続指定し、Enter / Space / Esc で終了することもできます。

## インストール

`UCAD-v0.2.0-x64-one-click.zip` を推奨します。初回の公開証明書信頼設定時のみ UAC が表示され、その後の署名済み MSIX インストールは通常ユーザーで実行されます。

## 次の段階

v0.3 では同じコマンド基盤の上に LINE、PLINE、RECTANGLE、CIRCLE、ARC と Undo / Redo を実装します。
