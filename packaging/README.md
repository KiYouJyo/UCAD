# UCAD GitHub Packaging

UCAD GitHub releases use a signed MSIXBundle plus a small one-click bootstrap package.

## Trust model

- The private PFX is **never committed** to the repository.
- GitHub Actions receives the PFX only through `GH_RELEASE_CERTIFICATE_BASE64` and `GH_RELEASE_CERTIFICATE_PASSWORD`.
- The Release workflow signs the MSIXBundle with SHA-256 and a trusted timestamp, then exports only the public `.cer` file.
- The public certificate is embedded in the one-click ZIP and its thumbprint is pinned in generated installer metadata.
- On first installation, the bootstrap requests UAC elevation only for importing the public certificate into `LocalMachine\TrustedPeople`.
- The normal installer process then verifies Release SHA-256, verifies the MSIX signer, and installs with `Add-AppxPackage`.
- Uninstall uses `Remove-AppxPackage` and intentionally retains the trusted public certificate so later UCAD releases can update under the same publisher identity.

## Release assets

A valid stable GitHub Release contains exactly:

```text
UCAD_<package-version>_x64.msixbundle
UCAD-v<display-version>-x64-one-click.zip
SHA256SUMS.txt
```

The one-click package is generated by `New-GitHubOneClickInstallerPackage.ps1` and validated by `Test-GitHubOneClickInstallerPackage.ps1` in CI before publication.

See `docs/RELEASE-PROCESS.md` for the full release pipeline.
