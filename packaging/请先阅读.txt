UCAD GitHub 一键安装包
======================

推荐安装方式：双击“① 安装UCAD.cmd”。

安装器会：
1. 从当前版本的官方 GitHub Release 下载签名后的 x64 MSIXBundle；
2. 按 SHA256SUMS.txt 校验下载内容；
3. 验证随安装器附带的 UCAD 公钥证书及证书指纹；
4. 将该证书加入当前 Windows 用户的 TrustedPeople 证书库；
5. 通过 Windows Add-AppxPackage 安装 UCAD；
6. 安装完成后启动 UCAD。

无需管理员权限。卸载请双击“② 卸载UCAD.cmd”。
卸载应用时不会删除已信任的 UCAD 发布证书，以保证后续版本升级仍可使用相同发布身份。

项目主页：https://github.com/KiYouJyo/UCAD
