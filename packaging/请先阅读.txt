UCAD {{DISPLAY_VERSION}} 一键安装包

用途：
- 双击“① 安装UCAD.cmd”即可安装 UCAD。
- 双击“② 卸载UCAD.cmd”即可卸载 UCAD。

安装位置：
%LOCALAPPDATA%\Programs\UCAD

安装过程：
1. 从 UCAD GitHub Release 下载官方 x64 程序包。
2. 下载同一 Release 的 SHA256SUMS.txt 并校验程序包 SHA-256。
3. 校验通过后安装到当前 Windows 用户目录。
4. 创建开始菜单和桌面快捷方式。
5. 安装完成后启动 UCAD。

特点：
- 不要求管理员权限。
- 不安装证书。
- 不修改系统级 PowerShell 执行策略。
- 不依赖 Microsoft Store。

提示：
- 安装时需要能够访问 GitHub Releases。
- 如果 UCAD 正在运行，安装/更新时会先关闭现有 UCAD 进程。
- 当前一键安装器面向 Windows x64。
