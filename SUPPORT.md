# UCAD Support

For bugs, regressions, packaging problems, or feature requests, use the GitHub issue templates in this repository.

When reporting an installation problem, include the UCAD version, Windows version, architecture, the visible error message, and the local installer log at `%LOCALAPPDATA%\UCAD\Logs\installer.log` when available. Do not post private keys, PFX files, certificate passwords, access tokens, or other secrets.

UCAD v0.x is early-stage software; compatibility and file-format support are intentionally limited while the CAD core is being established.
