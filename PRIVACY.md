# UCAD Privacy

Last updated: 2026-08-15

UCAD v0.1.0 does not require an account and does not include telemetry, advertising, analytics, or personal-data collection. The application itself is designed to work locally.

The optional GitHub one-click installer connects to GitHub only to read the selected UCAD Release, download its MSIXBundle and checksum manifest, and verify those release assets before installation. Installer logs are stored locally under `%LOCALAPPDATA%\UCAD\Logs`.

Future features that materially change this behavior must update this document before release.
